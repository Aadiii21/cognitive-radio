# Cost-Aware Cognitive Radio Framework

A software-based cognitive radio research project investigating joint
channel switching and adaptive modulation under time-varying channel
conditions, with explicit consideration of switching cost and packet
reliability.

## Project Objective

The framework investigates when a radio should:

- Remain on its current channel and adapt its modulation.
- Switch to another channel with better conditions.
- Jointly select a channel and modulation while accounting for handoff cost.

The intended objective is to improve useful delivered throughput while
maintaining packet reliability and accounting for switching downtime.

## Current Implementation

### Python Simulation

- Three-channel time-varying SNR model (AR(1) interference + burst events).
- Baseline and cost-aware cognitive controllers.
- Reliability-constrained controller with target PDR and dwell-time enforcement.
- Calibrated controller using empirical GNU Radio packet-success models.
- Multi-seed (30 seeds) and paired-seed experiments.
- Switching dwell-time experiments.
- Simulation metrics and statistical result analysis.

### GNU Radio Receiver Experiments

- BPSK, QPSK and 16-QAM packet receiver with RRC pulse shaping.
- Equal-average-power constellation normalization.
- Timing recovery and carrier recovery (Costas loop).
- Pilot-assisted gain correction.
- Synchronization and payload decoding.
- Packet-level SER, BER and PDR evaluation (10 seeds, all PASS).

### Calibration and Estimation

- Coarse and refined equal-power modulation calibration.
- Logistic packet-success models (leave-one-seed-out cross-validation).
- Matched clean/noisy path channel SNR calibration.
- Synthetic three-channel SNR estimator validation (error < 0.01 dB).
- Calibrated cognitive controller with noise-to-SNR mapping.

### Hardware Interfaces

- **RTL-SDR** (RTL2838, R820T tuner): IQ capture, spectral SNR estimation, 3-channel sensing at 500/501/502 MHz.
- **ADALM-Pluto** (AD9363A, Rev C, firmware v0.32): IQ capture via libiio/GNU Radio IIO, 3-channel sensing, TX waveform preparation.
- Dual-sensor hardware experiment: independent RTL-SDR and Pluto measurements driving cognitive controller decisions.

## Modulation Configuration

| Modulation | Nominal Rate |
|---|---:|
| BPSK | 1 bit/symbol |
| QPSK | 2 bits/symbol |
| 16-QAM | 4 bits/symbol |

All three constellations normalized to equal average symbol power
before comparative receiver calibration.

Waveform parameters: 2.4 MSPS, 600 ksym/s, 4 samples/symbol, RRC roll-off 0.35.

## Experimental Results

The project contains results from:

- Multi-seed controller comparisons (630 runs: 30 seeds × 3 environments × 7 strategies).
- Switching dwell-time sweeps.
- Equal-power modulation calibration.
- Refined packet-success calibration.
- Logistic packet-success model fitting and validation.
- Channel noise-to-SNR calibration.
- Three-channel SNR estimator testing.
- Hardware dual-sensor measurements and controller decisions.

Key finding: The **calibrated hybrid strategy** (using empirical packet-success models) achieves the highest throughput across all interference levels while maintaining competitive PDR. The uncalibrated hybrid strategy underperforms due to model mismatch.

Consolidated dataset: `results/calibrated_multi_seed_results.csv`
Paired statistical analysis: 95% confidence intervals via `src/paired_seed_analysis.py`

  --metadata results/baseband/bpsk_seed42.json

**Note:** RF transmission is DISABLED by default. Verify antenna suitability, frequency legality, and use appropriate attenuation before enabling TX.

## Current Limitations

- No physical RTL-SDR or ADALM-Pluto RF transmission has been validated (RX-only tested).
- Controlled Pluto→RTL-SDR conducted/over-the-air link not yet demonstrated.
- Results are from software simulation and GNU Radio simulated channels.
- Noise voltage is not equivalent to SNR in dB (calibration mapping required).
- Logistic packet-success models calibrated over measured transition ranges; predictions outside ranges are boundary approximations.
- Three-channel SNR estimator validated using synthetic pilot-plus-noise test.
- Sample-rate offset, multipath, and long-term timing drift not fully validated.
- ML/DL offline analysis not yet implemented (dataset ready).
